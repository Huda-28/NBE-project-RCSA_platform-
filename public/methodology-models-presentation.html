02 / 13 · Dual-Engine Architecture

Strict Separation: Deterministic Python Engine vs. Advisory Hybrid AI

The language model never calculates loss figures, assigns RRF percentages, or approves risks; every model payload passes a 15-field sanitizer first.

Stage 1: Advisory Multimodal & Hybrid AI (TS)
  • Multimodal & Table Parsing: Reads PDF tables, DOCX, XLSX, CSV, PPTX, JSON plus PNG/JPG/WebP scans via ViT/Swin Vision OCR.
  • 2-Stage Hybrid Retrieval: Fuses BM25 with 192-dim / gemini-embedding-2 vectors via RRF (k=60) + Stage-2 reranking.
  • Taxonomy Binding: Suggests Basel L1–L3 (84 nodes) and CBE ESG (34 cases) with verbatim quotes & pages.
Stage 2: Sanitization Perimeter (Guardrails)

stripForbiddenLlmFields() forcibly removes any restricted quantitative or governance key if an LLM attempts to generate it:

inherent_eal · inherent_rating · inherent_risk_score · rrf_applied · rrf_percentage · residual_eal · residual_rating · residual_risk_score · control_effectiveness_rating · overall_nfi_score · overall_nfi_rating · is_key_risk · key_risk · approval_status · approved_by
Stage 3: Deterministic Engine (Python Decimal)
  • Phase 2A: Computes Inherent EAL using fixed-precision Decimal and EI880:EI884 anchors.
  • Phase 2B: Evaluates eligible IMPLEMENTED controls across the 3×3 RRF matrix (MAX rule).
  • Phase 2C: Aggregates Slide 4 NFI (4×5 + "-") and computes residual-only Key Risk.

Financial Impact Bands, Official Anchors (EI880:EI884) & Historical Calibration

Exact Decimal arithmetic free of floating-point drift, implementing NBE methodology pages 3, 5, and 6 alongside automatic historical loss checks.

Official EGP Impact Bands & EI880:EI884 Reference Anchors
Band Severity Official EGP Range Reference Anchor
L Low Up to 150,000 EGP 50,000

Deterministic Inherent Loss Formulas
Inherent EAL = Avg_Impact_EGP × Freq_Multiplier

Frequency Multipliers: 0.5 (Biennial), 1.0 (Yearly), 2.0 (Semi-Annual), 4.0 (Quarterly), 12.0 (Monthly), 52 (Weekly), 250 (Daily).

Historical Loss Calibration Alert (< 75%)

The platform cross-checks every drafted Inherent EAL against actual 2-year historical loss events for the unit. Whenever an estimate is below 75% of realized losses, a calibration flag alerts both Maker and Checker.

04 / 13 · Controls Engine (Phase 2B)

Control Evaluation, 3×3 Official RRF Matrix & Residual Risk Calculation

Conservative MAX RRF selection over relevant IMPLEMENTED controls only, enforcing 0% credit for PROPOSED controls and the 7 official cadences.

Official 3×3 Risk Reduction Factor Matrix (OFFICIAL_RRF_MATRIX · EG889:EI897)
Execution Mechanism Preventive Detective Corrective
Automated Control 95% 85% 50%
Semi-Automated Control 90% 80% 40%
Manual Control 75% 60% 30%
1. Conservative MAX RRF Rule

Selects the highest eligible control percentage (MAX) rather than summing multiple controls, preventing over-optimistic residual risk reductions.

2. Zero Credit for Proposed Controls

Only IMPLEMENTED controls directly relevant to the threat receive RRF credit. Controls marked PROPOSED are held strictly at 0%.

3. Residual Loss Equation
Residual EAL = Inherent EAL × (1 − MAX RRF)

Example: 600,000 EGP × (1 − 0.90) = 60,000 EGP Residual EAL.

05 / 13 · Governance Rules (Phase 2C)

Slide 4 NFI (4×5 + "-"), Basel Taxonomy (84), CBE ESG (34) & Residual Key Risk

Deterministic validation of non-financial evidence, worst-case dimension aggregation, and strict enforcement of NBE residual-only Key Risk criteria.

1. Non-Financial Impact Matrix (4×5 + "-")

Evaluates 4 independent dimensions from 1 to 5: Service/Customer Disruption, Reputation, Regulatory/CBE, and Legal/Judicial.

"-" Non-Applicable Handling:
Supports "-"/NA (e.g., no judicial exposure) with mandatory written justification, then computes MAX over applicable dimensions.
2. Basel (84) & CBE ESG (34) + Acceptability

Enforces strict parent-child paths across 84 Basel L1–L3 nodes and 34 CBE ESG cases (E / S / G), plus "Other" inputs.

Acceptability Integrity:
Blocks selecting Category (1) Acceptable whenever an open remediation Action Plan exists on the risk row.
3. Strict Residual-Only Key Risk Criteria

Following NBE audit feedback, inherent scores never trigger Key Risk status. Key Risk = Yes applies exclusively when:

(1) residual_financial_rating ∈ { H, VH, C }
(2) OR MAX(applicable NFI) ∈ { H, VH, C }

07 / 13 · Hybrid Retrieval & Reranking

Inside Two-Stage Hybrid RAG: Tables + Vision OCR + RRF (k=60) + Stage-2 Reranker

How V5 combines table-preserving Markdown chunking, ViT/Swin multimodal OCR, BM25 + gemini-embedding-2 vectors via RRF (k=60), and Stage-2 reranking.

Stage 0: Table Reconstruction & ViT/Swin Vision

Reconstructs multi-column PDF/DOCX/HTML tables into Markdown tables whose header rows repeat across chunk splits (table-chunker.ts), while vision-document-parser.ts extracts embedded images and scanned pages via ViT/Swin VLM.

Stage 1: BM25 + Dense Vectors via RRF (k=60)

Repairs 30+ Identity-H Lam-Alef ligatures, scores bilingual BM25 across 9 operational synonym clusters, computes gemini-embedding-2 / 192-dim dense vectors, and fuses pools using Cormack et al. RRF (k=60).

Stage 2: Precision Reranker
Score = 0.32·RRF + 0.68·(ConceptCov + Bigrams + Codes + Table)

rerankCandidatesWithStage2() penalizes short boilerplate headers and boosts multi-concept, numeric code (MT950/AML), and TABLE matches.

Security-First Multimodal & On-Demand Reanalysis

Both initial uploads and pre-existing documents ("تحليل بصري" reanalysis) run through repairArabicPdfText, quarantinePromptInjection, and redactBankingPii before indexing, while logging VISION_DOCUMENT_EXTRACT events.

Banking AI Guardrails: PII Redaction, Injection Quarantine & 5-Badge Lineage

Defense-in-depth aligned with OWASP LLM Top 10 and NIST AI RMF protecting customer identifiers, blocking embedded document attacks, and auditing every cell.

Banking AI Security Perimeter (Pre & Post Inference)
  • 1. redactBankingPii(): Automatically masks Egyptian IBANs (EG...), 14-digit National IDs, and 16-digit PAN card numbers before any prompt leaves the server.
  • 2. quarantinePromptInjection(): Detects instruction-override patterns inside uploaded SOP/audit files and isolates content in non-executable tags (OWASP LLM01).
  • 3. stripForbiddenLlmFields(): Strips 15 restricted scoring and approval fields to guarantee mathematical determinism.
Five Cell-Level Data Provenance Badges
  • Original Baseline: Imported verbatim from an earlier approved RCSA cycle.
  • AI Proposed: Extracted from policy evidence and accepted by the Maker.
  • Draft Edit: Manually edited by the Maker; shows before/after diff to Checker.
  • Python Calculated: Deterministic Python Decimal computation (locked against manual edits).
  • Checker Approved: Cryptographically timestamped & locked by independent Checker.

Strict Separation: Deterministic Python Engine vs. Advisory Hybrid AI

The language model never calculates loss figures, assigns RRF percentages, or approves risks; every model payload passes a 15-field sanitizer first.

Stage 1: Advisory Hybrid AI (TypeScript)
  • Document Parsing: Reads PDF, DOCX, XLSX, CSV, PPTX, JSON and repairs Arabic Lam-Alef ligatures.
  • Hybrid Retrieval: Fuses BM25 lexical matching with 192-dim / gemini-embedding-2 vectors via RRF.
  • Taxonomy Binding: Suggests Basel L1–L3 (84 nodes) and CBE ESG (34 cases) with verbatim quotes & pages.

stripForbiddenLlmFields() forcibly removes any restricted quantitative or governance key if an LLM attempts to generate it:

  • Phase 2A: Computes Inherent EAL using fixed-precision Decimal and EI880:EI884 anchors.
  • Phase 2B: Evaluates eligible IMPLEMENTED controls across the 3×3 RRF matrix (MAX rule).
  • Phase 2C: Aggregates Slide 4 NFI (4×5 + "-") and computes residual-only Key Risk.

Deterministic Inherent Loss Formulas

Historical Loss Calibration Alert (< 75%)

04 / 13 · Controls Engine (Phase 2B)

Control Evaluation, 3×3 Official RRF Matrix & Residual Risk Calculation

Conservative MAX RRF selection over relevant IMPLEMENTED controls only, enforcing 0% credit for PROPOSED controls and the 7 official cadences.

Official 3×3 Risk Reduction Factor Matrix (OFFICIAL_RRF_MATRIX · EG889:EI897)
Execution Mechanism Preventive Detective Corrective
Automated Control 95% 85% 50%
Semi-Automated Control 90% 80% 40%
Manual Control 75% 60% 30%
1. Conservative MAX RRF Rule

Selects the highest eligible control percentage (MAX) rather than summing multiple controls, preventing over-optimistic residual risk reductions.

2. Zero Credit for Proposed Controls

Only IMPLEMENTED controls directly relevant to the threat receive RRF credit. Controls marked PROPOSED are held strictly at 0%.

3. Residual Loss Equation
Residual EAL = Inherent EAL × (1 − MAX RRF)

Example: 600,000 EGP × (1 − 0.90) = 60,000 EGP Residual EAL.

05 / 13 · Governance Rules (Phase 2C)

Evaluates 4 independent dimensions from 1 to 5: Service/Customer Disruption, Reputation, Regulatory/CBE, and Legal/Judicial.

"-" Non-Applicable Handling:
Supports "-"/NA (e.g., no judicial exposure) with mandatory written justification, then computes MAX over applicable dimensions.
2. Basel (84) & CBE ESG (34) + Acceptability

Enforces strict parent-child paths across 84 Basel L1–L3 nodes and 34 CBE ESG cases (E / S / G), plus "Other" inputs.

Acceptability Integrity:

Following NBE audit feedback, inherent scores never trigger Key Risk status. Key Risk = Yes applies exclusively when:

(1) residual_financial_rating ∈ { H, VH, C }
(2) OR MAX(applicable NFI) ∈ { H, VH, C }

07 / 13 · Hybrid Retrieval Engineering

Inside Hybrid RAG: Arabic Repair + BM25 IDF + Dense Vectors + RRF (k=60)

How rag-service.ts repairs Arabic PDF ligature artifacts and combines lexical precision with semantic embeddings via Cormack et al. RRF.

Leg 1: Arabic Normalization + BM25

Repairs 30+ broken Identity-H Lam-Alef ligatures prior to tokenization, then runs bilingual BM25 scoring expanded across 9 operational risk synonym clusters (fraud, cyber, AML, SLA, vendor, reconciliation, credit, liquidity, ESG).

Leg 2: Persistent Dense Vectors

Computes semantic vectors using gemini-embedding-2 or local 192-dim projections, stored in SQLite (embedding_json) to eliminate re-embedding cost and bridge Arabic/English terminology cleanly.

Reciprocal Rank Fusion (RRF, k=60)
RRF(d) = 1/(60 + rank_vec(d)) + 1/(60 + rank_bm25(d)) + boost

Scale-invariant fusion elevates clauses surfacing in both legs and adds targeted boosts for audit findings and historical loss records.

Indexing Parameters & Scanned PDF Protection

Sliding chunks use 1,400 characters with 250-character overlap (Top 8 Fast / Top 16 Accurate). If extracted text density indicates an image-only scan, low_text_ocr_warning alerts the Maker immediately.

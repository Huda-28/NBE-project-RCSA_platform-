# وظائف الصفحات والتصدير — نسخة ما قبل AI Agent

| الصفحة | وظيفتها | الصلاحيات الأساسية |
|---|---|---|
| لوحة المعلومات | المؤشرات الحالية وحالة الوحدات والانتقال للتقييمات | حسب الوحدات المصرح بها؛ Admin رؤية شاملة |
| الوحدات التنظيمية | استعراض الوحدات وكل إصدارات RCSA بالتواريخ وسجل التعديل ومقارنة الإصدارات | قراءة حسب الصلاحيات؛ إضافة وحدة بواسطة Admin |
| إعداد تقييم جديد | اختيار وحدة، رفع/استعراض مستندات، استيفاء بيانات، حساب أولي، وإنشاء مسودة | Maker وAdmin |
| مصفوفة تقييم المخاطر | مراجعة المخاطر والضوابط، إعادة الحساب، NFI/ESG، المعاينة، الاعتماد، والتصدير | Maker للتعديل وChecker للاعتماد؛ Auditor للقراءة؛ Admin للإشراف |
| المراجعة والاعتماد | قائمة التقييمات ومتابعة قرارات Maker–Checker | Maker وChecker وAdmin حسب الوحدة |
| سجل التعديلات | من عدّل ماذا ومتى، وسجل الإجراءات الأمنية والاعتماد | Auditor وAdmin |
| إدارة المستخدمين | عرض الحسابات ومنح صلاحيات وإضافة وحدات تنظيمية | Admin فقط |
| وكيل الذكاء الاصطناعي | شاشة تصميم تمهيدية؛ التحليل والتوليد الذكي غير منفذين بعد | لا يُعتبر عاملًا في هذه النسخة |

## معاينة قبل التصدير
- داخل «مصفوفة تقييم المخاطر»: زر «ملخص الجاهزية ومعاينة الأعمدة الرسمية» يعرض جدول معاينة القراءة فقط للأعمدة C..AE والحالة/النواقص.
- المعاينة **ليست** عرضًا مطابقًا بصريًا لكل تنسيقات وخلايا ملف Excel. الملف النهائي يحتفظ بتنسيق القالب الأصلي نفسه.

## Excel الرسمي
- بعد اكتمال التقييم، وتوثيق NFI/ESG/قرار القبول، واعتماد Checker، يظهر زر «تصدير Excel المعتمد».
- مدعوم حاليًا لوحدة القروض المشتركة فقط (8 مخاطر ومسارات الصفوف الأصلية)، لأن قالبها الرسمي الأصلي هو المتوفر.
- اسم الملف: `RCSA_<Business Unit name>_<actual approved date YYYY-MM-DD>.xlsx`، أو `date-unavailable` لو تاريخ الاعتماد غير مسجل (بدون اختراع تاريخ).
- الملف مطابق لبنية قالب القروض المشتركة المرفوع: تنسيق الخلايا المدمجة والتبويبات والجداول والصيغ غير المتغيرة. مع تعبئة أعمدة التقييم، L1 في AD، وESG في AE.
- باقي Business Units **لا تتوفر لها قوالب Excel الرسمية الخاصة بها**؛ لا يصح الادعاء بتصدير مطابق قبل توفيرها وتكييف خريطة الصفوف.

## شرط الإطلاق
هذه نسخة مرشحة للاختبار؛ يلزم اختبار حقيقي للمتصفح والأدوار ومسار اعتماد Checker والتصدير من API بعد تثبيت Node dependencies. نجاح اختبارات Python أو صحة بنية XLSX ليس شهادة جودة بيانات بنكية فعلية.
